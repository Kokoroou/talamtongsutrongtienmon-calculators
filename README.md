# Sổ Truyền Công

Công cụ hỗ trợ game "Ta làm tông sư trong tiên môn": chọn đệ tử cần trục xuất, xem nên truyền công cho ai để tăng nhiều cấp nhất.

**https://kokoroou.github.io/tongsu-calc/**

  <img src="docs/desktop.png" alt="Máy tính" width="560">
</p>

**Kế hoạch truyền công** (nút danh sách ở màn Đệ tử): nhập ngưỡng tổng giá trị, app gợi ý ai truyền cho ai để những người ở lại tăng nhiều cấp nhất, rồi mới đến ít bước nhất. Hiện số bước, tổng cấp tăng và mức tăng từng chuyên môn, kèm các phương án ít bước hơn; áp dụng cả kế hoạch một lần, hoàn tác một lần.

Dữ liệu lưu trong trình duyệt, có thể sao lưu ra file JSON. Không cần build: mở `index.html` hoặc `npx serve .`

```bash
npm test
```
