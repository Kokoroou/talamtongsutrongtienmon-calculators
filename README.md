# Sổ Truyền Công

Công cụ hỗ trợ game "Ta làm tông sư trong tiên môn": chọn đệ tử cần trục xuất, xem nên truyền công cho ai để tăng nhiều cấp nhất.

**https://kokoroou.github.io/tongsu-calc/**
